## Sources evaluated and rejected

| Source | Why not |
|---|---|
| Open-Meteo API | free tier is for non-commercial use only |
| BDEW standard load profiles (electricity and gas) | licence not open. Not used as data or as a validation reference |
| pvlib-python (BSD-3) | licence fine, but its compiled dependencies are blocked by Windows application control on the build machine. The same published models were re-implemented in `data/solar_model.py` (see DECISIONS D-004) |
